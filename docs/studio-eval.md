# Test Studio eval: plain-English tests against real bugs

15 instructions a tester would type, on a local login and sign-up site, each with the bugs it describes (19 bugs). Planner: **rule-based (no AI model)**. Generated by `python -m scripts.studio_eval`.

A bug is **caught** when the test passes on the healthy site and fails with that bug switched on. A test that fails the healthy site is a **false alarm**, and catches nothing.

| Result | Value |
| :--- | ---: |
| Instructions turned into a saveable test | 15 of 15 |
| Saveable tests that pass on the healthy site | 15 of 15 |
| False alarms | 0 |
| **Bugs caught** | **18 of 19 (95%)** |
| Bugs caught, cases the planner was improved on (10) | 12 of 12 |
| **Bugs caught, held-out cases (5, never tuned on)** | **6 of 7** |

The rule-based planner was improved while looking at the first cases; the held-out cases were written afterwards, in different words, as a fairer measure of instructions it has not seen, and the planner was not changed for them. The held-out miss is in the instruction itself: the text it checks, "Your account", is also on the sign-in page the bug sends you to ("Sign in to your account"; text checks ignore case), so no test written from it can tell the two pages apart. Checking "Signed in as" would.
