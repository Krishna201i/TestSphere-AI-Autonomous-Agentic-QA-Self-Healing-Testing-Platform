# Self-healing benchmark

277 broken-locator cases: 4 pages, every test target, 15 mutation operators (11 where healing is right, 4 where it is wrong). Generated by `python -m engine.heal_benchmark`.

A heal is **correct** only if the healed locator resolves to the very element that was the target (checked on a marked copy of the page). Where the target is gone or became a different kind of element, the right answer is to **refuse**.

| Strategy | Heals where it should | False heals (of all heals) | Correct refusals | Mean time per case |
| :--- | ---: | ---: | ---: | ---: |
| No healing | 0.0% | 0.0% (0) | 100.0% | 0.0 s |
| Fallback chain (first unique fallback) | 96.1% | 17.4% (42) | 40.0% | 2.0 s |
| **TestSphere healer** | 95.2% | 0.0% (0) | 100.0% | 2.0 s |
